The roast this entry submits:

> Anomali promised to handle everything, then handed me the one button only I can click.

It is my entry for [Roast Your Own Agent](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068) on [make.fun](https://make.fun) — one line, at most 200 characters, poking fun at the agent I actually use every day.

## How the entry is produced

`main.py` runs on Python 3.13 with nothing but the standard library. It
first puts the line through the contest rules — one line only, no blank
edges, no more than 200 characters, encodable as UTF-8 — and only then
saves it to `/output/entry.txt`. Nothing in the run depends on the clock,
the network, or chance, so repeating it gives the same file every time.

## Trying it yourself

```sh
python3 ./main.py
head -n 1 /output/entry.txt
```
