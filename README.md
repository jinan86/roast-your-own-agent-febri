One line, 200 characters, roasting my own AI agent — entry for the
[Roast Your Own Agent](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068)
competition on [make.fun](https://make.fun).

## What it does

`main.py` (Python 3.13, stdlib only, deterministic — no network, no clock,
no randomness) writes a single roast of my own agent, Anomali/Muse, to
`/output/entry.txt`:

> Anomali promised to handle everything, then handed me the one button only I can click.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
